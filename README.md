# Sleep-AcademicPerformance-Analysis
Progetto sviluppato per analizzare la correlazione tra le abitudini del sonno e i risultati accademici in un campione di studenti universitari.
Il progetto implementa una pipeline di analisi dati in Python utilizzando le principali librerie del settore:
- Manipolazione dati (Pandas): caricamento,gestione,pulizia dei dati
- Analisi statistica: calcolo di statistiche descrittive (media, mediana, deviazione standard) e analisi della correlazione per identificare eventuali tendenze significative tra le ore di sonno e i punteggi d'esame
- Visualizzazione dati (Seaborn, Matplotlib): creazione di grafici per il confronto tra medie (barplot) e l'analisi della distribuzione (istogrammi con KDE)
- Implementate funzioni personalizzate per categorizzare il campione in base alla qualità del sonno
